# M3ly GitHub Mirror

This repository is a **non-authoritative public mirror/evidence surface** for M3ly.

- **Authoritative source:** private GitLab project `m3ly/mely`.
- **GitHub role:** backup, public evidence, reviewable release artefacts, and independently verifiable checks only.
- **Do not develop production changes here.** Changes must originate from the authoritative source and pass the mirror policy before publication.
- **No production credentials, secrets, private configuration, user data, logs, database dumps, signing material, or private CI/CD data may be mirrored.**
- A GitHub commit is not a production release and must never trigger production deployment.

See [`MIRROR_POLICY.md`](MIRROR_POLICY.md), [`SECURITY.md`](SECURITY.md), and [`MIRROR_SOURCE.json`](MIRROR_SOURCE.json).
