# Security Policy

M3ly treats this GitHub repository as a public mirror/evidence surface, not as the production source of truth.

## Reporting

Do not publish credentials, private keys, personal data, message contents, exploitable secrets, or sensitive operational details in public issues or pull requests.

If you believe this mirror contains sensitive material, stop redistributing it and report the affected path and commit identifier through M3ly's private security/contact channel.

## Repository guarantees

This repository must contain no production credentials and must not be configured as a production deployment source. Public material should be reproducible from an explicitly reviewed revision of the authoritative GitLab source after sanitisation.

## Scope

Security fixes intended for production must be handled through the authoritative GitLab workflow. GitHub may preserve public evidence or reviewed patches, but GitHub review or CI success alone does not authorize a production change.
